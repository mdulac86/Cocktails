# Bar à cocktails

Appli web installable (PWA) en français : tu indiques les bouteilles de ton bar, elle propose plus de 300 cocktails (simples, normaux ou élaborés), un sélecteur « J'ai envie » et un carnet d'avis.

- Aucune donnée personnelle dans le code. L'inventaire, les marques et les avis restent dans le navigateur de l'appareil (localStorage).
- Fonctionne hors ligne grâce au service worker.
- Installation : ouvrir l'adresse GitHub Pages, puis « Ajouter à l'écran d'accueil » (iPhone : Partager) ou « Installer l'appli » (Android).

Fichiers : `index.html`, `manifest.webmanifest`, `sw.js`, icônes PNG.
